# Frozen protocol

## Partitioning

KAIST folds leave out the 1.0,1.5,3.0kW motor, respectively. The remaining two motors alternate as inner fitting/validation domains. Mean validation record BA selects the epoch, then mean window BA breaks ties; an exact tie selects the earliest checkpoint. Reinitialize and refit both source motors for that number of epochs. The cosine schedule keeps a120-epoch horizon even during the shorter refit.

CEITEC target groups and source partitions (Nm):

| Target | Train | Validation | Test |
|---|---|---|---|
| Low | 15,25,30 | 20,35 | 0,5,10 |
| Middle | 0,5,25,30 | 10,35 | 15,20 |
| High | 0,5,15 | 10,20 | 25,30,35 |

CEITEC selects validation window BA, then record BA, then earliest epoch; validation loads are never fitted. All windows of each record stay together. Every record is tested once across the three outer folds. The serialized window indices are authoritative.

## Optimization and decision rule

- Seeds:20261014,20261015,20261016.
- 120epochs,16minibatches/epoch,96windows/minibatch.
- Draw class uniformly, record uniformly within class, window uniformly within record.
- Adam lr0.001, no weight decay; cosine horizon120, minimum1e-5.
- Validate every10epochs. Network dropout0.2 only during training.
- Average three seed probabilities. Window or record probability strictly greater than0.5 means fault; ties are healthy.
- Record score averages every eligible window of the acquisition; it is not majority voting over hard labels.
- BA=(healthy recall+fault recall)/2. Report unweighted mean over outer folds; do not pool folds with different class counts.

The frontend is per-window and label-free. StandardScaler for classical features is fitted on source fitting windows only. No target labels/data influence checkpoint selection or fitted normalization. Previous method development did inspect these benchmark test folds; a future untouched acquisition is needed for independent confirmation.

## Supplementary analyses

The four LR protocols are fixed in `supplementary.py`. Random splitting deliberately shares acquisitions to provide a diagnostic comparison; it is not a valid independent record-level estimate. A/B recognition changes the target label to acquisition group, and differences in fault settings remain confounded with group.

Frequency explanations use the final frozen models with no retraining. Normalize the first-readout-layer L2 norm across channel/hidden dimensions by the sum over64positions. Average nine profiles per dataset. For occlusion, zero all input channels in each consecutive16-bin input band and measure absolute change in the fold's three-model mean fault probability. Average windows within each fold, then equally across folds.

Nominal input bands and readout positions have aligned coarse indices, but convolutional receptive fields overlap27bins. Norms are parameter magnitudes, not causal contributions. Zeroed bands may be outside the original spectrum distribution. The analyses establish frequency-dependent sensitivity without asserting a unique physical fault source.

## Reproducibility scope

Released checkpoints reproduce the archived predictions within1e-4 absolute probability tolerance. The portable training implementation is checked for execution and matches the documented architecture, sampling, optimizer, schedule and selection logic. Full retraining of every seed was not repeated merely for packaging. Cross-platform retraining is not promised to be bitwise identical.

This compact repository supplies FPP-Net and six spectral classical baselines. The full comparison/ablation tables are archival evidence; other neural comparators, MiniRocket, latency benchmarking, and the raw acquisition-anomaly figure generator are outside this compact implementation. No claim is made that every table can be regenerated by a single command here.
